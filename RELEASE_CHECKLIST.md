# Release checklist

This public portfolio edition demonstrates the application and synthetic test workflow.

- Validate product dimensions, print areas and physical samples with the supplier.
- Approve catalog prices, shipping coverage and customer policies.
- Select a payment gateway and verify its sandbox, callbacks and reconciliation.
- Review touch interaction, accessibility, device performance and multi-page A4 output.
- Configure TLS, persistent storage and independent verified backups on the selected host.
- Run order-to-production acceptance and rollback drills before public commerce launch.

Sample content and test checkout are provided for local evaluation.
