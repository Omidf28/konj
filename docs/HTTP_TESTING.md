# آزمون HTTP ایزوله

فرمان npm.cmd run test:http:isolated پوشه تصادفی konj-http-* زیر temp سیستم، fixture.sqlite و uploads مستقل می‌سازد، پورت آزاد روی 127.0.0.1 می‌گیرد و APP_ORIGIN و TEST_ORIGIN را فقط برای فرایند خودش تنظیم می‌کند. سرور پورت ۳۰۰۰، حساب فعلی مدیر و داده فروشگاه استفاده نمی‌شوند.

کد از فهرست مجاز src، public، scripts و تنظیمات در .http-tests/<id> کپی می‌شود؛ فایل .env، storage، .git و next-env اصلی کپی نمی‌شوند. وابستگی‌ها با junction به node_modules موجود متصل‌اند؛ نصب تازه‌ای انجام نمی‌شود. لینک در منابع رد می‌شود و شناسه دقیقاً ۳۲ رقم hex است. خروجی Next، next-env و تنظیم TypeScript داخل همین snapshot و توسط Git نادیده گرفته می‌شوند. ریشه Turbopack پروژه اصلی است تا وابستگی مشترک در محدوده workspace بماند؛ کد و داده آزمون مستقل‌اند.

health فقط در development و fixture معتبر fingerprint شناسه اجرا و مسیر دقیق دیتابیس/آپلود را نشان می‌دهد. smoke قبل از ساخت مدیر یا نوشتن، guard مسیر temp و پورت جدا را بررسی و fingerprint سرور را تطبیق می‌دهد. اجرای مستقیم test:http بدون fixture معتبر پیش از ساخت دیتابیس رد می‌شود. نشانگر مسیرها یا اسرار را افشا نمی‌کند؛ در تولید و توسعه عادی وجود ندارد و هیچ مجوزی را دور نمی‌زند.

runner برای آماده‌شدن سرور ۹۰ ثانیه و برای مجموعه تست سه دقیقه مهلت دارد. در پایان یا خطا فقط فرایند سرور ساخته‌شده خودش متوقف می‌شود؛ در Windows با PID ثبت‌شده و درخت فرایند. دیتابیس و آپلود آزمایشی حذف نمی‌شوند و مسیرشان برای بررسی چاپ می‌شود. رفتار توقف درخت فرایند در Linux آزموده نشده است. build اصلی و fixture پوشه خروجی مشترک ندارند؛ اجرای هم‌زمان build و HTTP ایزوله در این دور موفق بود. تغییر وابستگی‌ها هنگام آزمون توصیه نمی‌شود، چون node_modules مشترک است.

آزمون شامل صفحات فعلی فروشگاه و فایل GLB کامل بدن مرجع و مسیرهای سفارش، فایل خصوصی، مدیریت، تولید، تاریخچه و امنیت حساب با حساب موقت است. این آزمون HTTP است و جای مرورگر، WebGL، لمس و بررسی دیداری را نمی‌گیرد.

مرور مدیر ایزوله: --review-admin؛ پذیرش برگه/اصل فایل دوطرفه و پک: --review-fulfillment؛ داده ۲۹ سفارش برای صفحه‌بندی/تعارض: --review-orders. هر پرچم به scripts/http-isolated.mts داده می‌شود و سرور را تا Ctrl+C باز نگه می‌دارد. رمز چاپ‌شده فقط برای مدیر موقت همان fixture است؛ در اسناد/عکس ثبت نشود. پذیرش‌ها در R10_ACCEPTANCE.md آمده‌اند.
